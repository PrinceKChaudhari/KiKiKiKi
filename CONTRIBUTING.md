# Working on KIKIKIKI

KIKIKIKI is maintained by Prince K Chaudhari. Contact the repository owner through a GitHub issue before proposing substantial changes. Original additions are proprietary; review LICENCE.md and THIRD_PARTY_NOTICES.md before reusing code.

Use Node.js 22 LTS and pnpm 9.15.3. Install with `pnpm install --frozen-lockfile` and start development with `pnpm dev`.

Keep components under components/retroui, examples under preview/components, and technical guides under content/docs. Preserve third-party license notices and existing registry identifiers.

Before submitting a change, run `pnpm lint`, `pnpm build`, and `git diff --check`. Describe behavior changes and any checks that could not be completed.
