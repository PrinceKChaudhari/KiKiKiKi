KIKIKIKI is Prince K Chaudhari's playful UI showcase. Browse components, try themes, and explore the implementation without creating an account.

## What is included?

- Component previews and source examples.
- Theme previews and customization.
- Technical guides for the code included in this repository.

There are no memberships, paid plans, account dashboards, or premium downloads.

Start with the [setup guide](/docs/install), explore [components](/docs/components), or try [themes](/themes).
