KIKIKIKI itself runs on Next.js. Follow the [setup guide](/docs/install) to run this website.

## Component examples

Browse [components](/docs/components), inspect the source and manual dependency list, and use the provided React examples. Keep the supporting utilities, theme CSS, and import aliases consistent with your project.

The retained `components/retroui` path is an internal compatibility name. There is no KIKIKIKI account or registry setup step. Review LICENCE.md and THIRD_PARTY_NOTICES.md in the repository before reusing source.
