## Requirements

Use Node.js 22 LTS and pnpm 9.15.3.

## Run the website

```sh
git clone https://github.com/PrinceKChaudhari/KiKiKiKi.git
cd KiKiKiKi
pnpm install --frozen-lockfile
pnpm dev
```

Open http://localhost:3000. No account, authentication API, or payment configuration is required.

## Explore the code

Component implementations live in `components/retroui`, examples in `preview/components`, and guides in `content/docs`. Existing directory names are kept for import compatibility.

Component pages include usage examples and source. Install the dependencies listed in each manual example and review the repository's license files before copying code. This site does not provide a separate KIKIKIKI CLI registry or MCP service.

## Build and deploy

```sh
pnpm build
pnpm start
```

Import the repository's main branch into Vercel using the Next.js preset. The included vercel.json defines install and build commands. Optionally set NEXT_PUBLIC_SITE_URL to your public HTTPS URL for sitemap metadata.

See the [repository README](https://github.com/PrinceKChaudhari/KiKiKiKi#readme) for deployment details.
